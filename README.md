# ポケカ せどり管理ツール(ローカル版)

保有カードの売り時提案と、仕入れ候補の提案を行うローカルWebアプリ(Python + SQLite)。

## 起動
```
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...   # 画像からのカード自動判定(任意)
python app.py                  # http://127.0.0.1:8000
```
環境変数: `USD_JPY` `EUR_JPY` `FEE_RATE`(既定0.10) `ENABLE_SCRAPING=1`(ヤフオク取得・実験的) `POKECARD_DATA`(保存先)

## 機能
- 画像登録 → Claude Vision でカード名/弾/番号を推定(失敗時は手入力・編集可)
- 相場取得: Pokémon TCG API(公式、英語版中心)/ ヤフオク落札(実験的・既定オフ)/ 手入力・CSV(メルカリ等)
- 売り時提案: 30/90日中央値との乖離・モメンタム・今後のイベントから「今売る/待つ/様子見」と目安売値・時期
- 仕入れ候補: ウォッチ中カードを割安度・下げ止まり・イベント・ボラティリティでスコア化
- 売却記録(手数料・送料込みの純利益)、市場イベントの編集

## 注意
- 提案はヒューリスティックで、利益を保証しません。相場履歴が溜まるほど精度が上がります(定期的に「相場を更新」)。
- メルカリは公開APIが無く自動取得が規約で禁止のため、手入力/CSVにしています。ヤフオク取得は非公式で壊れやすく、実際のサイトでは未検証です。
- 初期イベントの日付は目安です。必ず確認してください。
